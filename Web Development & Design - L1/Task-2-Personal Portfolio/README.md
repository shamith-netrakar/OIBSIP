# Task 2 - Personal Portfolio

## Objective

Create a personal portfolio website that showcases my skills, projects, education, and contact information as a digital resume.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome

## Features

- Responsive profile/hero section
- About Me section
- Technical skills section
- Projects showcase
- Education section
- Contact section
- Smooth scrolling navigation
- Responsive design for desktop and mobile
- Social media links
- Download CV button
- Back-to-top button
- Typing text animation
