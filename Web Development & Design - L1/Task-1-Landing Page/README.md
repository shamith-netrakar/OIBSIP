# NXT Studio — Creative Studio Landing Page

A modern, responsive landing page created for the **Oasis Infobyte Web Development and Designing Internship — Level 1, Task 1**.

NXT Studio is a creative studio concept focused on photography, video editing, and visual storytelling. The website presents the studio's services, creative work, workflow, and contact information through a clean and modern dark-themed interface.

## 🎨 About NXT Studio

**NXT Studio** is a creative studio concept that brings together different forms of visual creativity under one identity.

The studio focuses on:

- Photography
- Video editing
- Visual storytelling
- Creative content
- Digital visual experiences

The project includes two creative service divisions:

### 📷 NXT CLICKZ

A photography-focused division dedicated to capturing people, products, events, and memorable moments through creative photography.

### 🎬 NXT EDITZ

A video-editing-focused division dedicated to transforming raw footage into engaging visual stories through creative editing.

## 🛠️ Technologies Used

The project was developed using:

- **HTML5** — Website structure and semantic content
- **CSS3** — Styling, layouts, animations, and visual effects
- **CSS Flexbox** — Flexible component layouts
- **CSS Grid** — Responsive grid-based layouts
- **Responsive Web Design** — Adaptation to different screen sizes
- **SVG** — Service icons
- **MP4** — Portfolio video

No JavaScript is required for the core functionality of this landing page.

## 🎨 Design System

The website follows a dark, modern, and minimal visual style.

### Color Palette

| Color | Hex Code | Usage |
|---|---|---|
| Black | `#000000` | Main background |
| Dark Gray | `#0D0D0D` | Alternate section background |
| White | `#FFFFFF` | Primary text |
| Light Gray | `#BDBDBD` | Secondary text |
| Blue | `#00A2FF` | Primary accent color |
| Hover Blue | `#33B5FF` | Hover states |

The blue accent is used for:

- Headings
- Buttons
- Navigation states
- Borders
- Icons
- Highlights
- Hover effects
- Visual emphasis
