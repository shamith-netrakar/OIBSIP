# Temperature Converter Website

## Oasis Infobyte Internship – Level 1 Task 3

A simple and interactive temperature converter built using HTML5, CSS3, and Vanilla JavaScript.

## Features

- Convert temperatures between Celsius, Fahrenheit, and Kelvin
- Input validation for invalid values
- Absolute-zero validation
- Displays converted values up to two decimal places
- Responsive and clean user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
